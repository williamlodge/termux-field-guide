# Contributing

Contributions are welcome, especially corrections caused by changes in Android, Termux, PRoot-Distro, Shizuku, Termux:X11, Magisk, KernelSU, APatch, or related upstream projects.

## Good contributions

- Correct outdated commands or package names.
- Add a primary-source citation for a changed behavior.
- Improve accessibility or mobile usability.
- Clarify differences between Termux, PRoot, ADB, Shizuku, root, and remote Linux.
- Report device/version-specific behavior without presenting it as universal.

## Evidence standard

For technical claims that can change, prefer upstream documentation and official project repositories over blogs, videos, reposts, or AI-generated summaries.

When reporting a compatibility issue, include:

- Android version
- Device model
- Termux installation source
- Termux version
- Relevant add-on/tool version
- Exact command or workflow
- Actual result
- Expected result
- Link to upstream documentation or issue when available

## Safety

Do not submit device-specific flashing commands as universal instructions. Bootloader, root, partition, and firmware procedures must clearly identify their scope and risks.
