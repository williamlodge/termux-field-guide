# Security Policy

Termux Field Guide is documentation, not privileged software, but its commands can affect devices, servers, accounts, and data.

## Reporting a security problem

Open a GitHub issue for documentation that:

- exposes credentials or secrets,
- recommends unsafe network exposure,
- contains a destructive command without adequate warning,
- could cause users to flash the wrong partition or firmware,
- incorrectly describes ADB/Shizuku/root privilege boundaries,
- or creates another meaningful security risk.

Do not publish real passwords, private keys, API keys, tokens, recovery codes, or personally identifying device/account information in an issue.

## Scope

Security reports about Termux, Android, Shizuku, Magisk, KernelSU, APatch, or another third-party project should also be reported through that project's own security process when appropriate.
